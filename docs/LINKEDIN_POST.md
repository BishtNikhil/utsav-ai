🏆 **Main Challenge 05: Celebration & Event Planner**
Introducing **UtsavAI (उत्सव AI)** — an autonomous event orchestrator powered by **Google Gemini 2.5 Flash** and a **Dynamic Constraint Graph**.

---

### 💡 The Core Problem: Beyond Flat Chatbots
In the live explainer session, Subject Matter Expert Srinivas laid down the real challenge:
> *"Event planning is not one single problem; it is a collection of connected smaller problems. Generating ideas is easy — turning them into an execution plan that dynamically balances budget, guest dependencies, vendor trade-offs, and deadlines is the true challenge."*

Most AI event planners simply wrap an LLM to spit out generic checklists. When things change, the user is forced to restart from scratch.

### 🔱 How UtsavAI Solves It:
Instead of static prompts, **UtsavAI models celebrations as an interconnected constraint mesh**:

1. **🔗 Dynamic Dependency Engine:** Headcount directly scales catering allocations, indoor floor space minimums (12 sq.ft/guest), and logistics with an automatic 7% contingency shield.
2. **💥 The SME "Change Test" Benchmark:** Passed with zero friction! When parameters shift (+50 guests, 10% budget cut, event advanced by 14 days), UtsavAI re-anchors the plan in real time without restarting.
3. **⚖️ Priority-Shielded Trade-Offs:** Refuses blind uniform cuts. When budgets tighten, it protects top-ranked priorities (e.g., shielding gourmet catering while rationalizing floral decor).
4. **🗓️ Milestone DAG:** Topological dependency graph enforcing strict prerequisites with auto-cascading date compression.
5. **🤝 Vendor Copilot:** Side-by-side quotation auditor that flags unquoted 18% GST, diesel generator fuel levies, and overtime penalties.

---

### 🛠️ Tech Stack & Engineering Rigor:
* **Generative Core:** Google Gemini 2.5 Flash (via Google AI Studio) with structured JSON schemas
* **Backend:** FastAPI (Python 3.12) with asynchronous non-blocking event loop
* **Resilience:** Deterministic local calculation engine ensures 100% zero-downtime fallback
* **Quality & Security:** 14 automated pytests passing in 1.1s, OWASP security headers, and strict Zero-Secret Law compliance
* **Deployment:** Live on Vercel Serverless & Edge CDN
